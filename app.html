    Backup and sharing

    Watchlist and review mode share one set of titles on this page. Export saves them all in the file format the separate Watchlist and Ratings pages use, so any of the three imports it, as well as files from earlier versions. Imports merge: nothing is removed, a title reviewed or changed more recently in the file takes the file’s version, and anything else only fills in what’s blank here. This page starts empty: to bring titles over, export them from the other pages and import them here. Taste profile for AI copies a summary you can paste into Claude.
